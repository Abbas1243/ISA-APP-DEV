# ISA Task App

An innovative Flutter-based task management application developed during the ISA-VESIT Internship Program 2024.

## About This Project

This project is the culmination of a 7-week internship conducted by the **International Society of Automation (ISA) - Maharashtra Section** in collaboration with **VESIT (Vivekanand Education Society's Institute of Technology), Mumbai**.

### Internship Timeline

- **Weeks 1-3**: Foundation Learning Phase
  - Comprehensive introduction to Flutter development
  - Learning Dart programming language fundamentals
  - Building small personal projects to solidify concepts
  
- **Week 4-6**: Team Development Phase
  - Collaborative development of the ISA Task App
  - Full-stack implementation from scratch
  - Integration of features and real-world application development
  
- **Week 7**: Review and Refinement Phase
  - Code reviews and quality assurance
  - Bug fixes and optimization
  - Final testing and deployment preparation

## Project Description

The ISA Task App is a comprehensive task management solution built with Flutter, designed to help users organize, track, and manage their daily tasks efficiently. This application showcases modern mobile development practices and was created entirely from scratch by the intern team during weeks 4-6 of the internship program.

## Getting Started

This project is built using Flutter, a cross-platform mobile framework developed by Google.

### Resources to Learn Flutter

- [Lab: Write your first Flutter app](https://docs.flutter.dev/get-started/codelab)
- [Cookbook: Useful Flutter samples](https://docs.flutter.dev/cookbook)
- [Flutter Documentation](https://docs.flutter.dev/)

### Prerequisites

- Flutter SDK installed and configured
- Dart SDK (included with Flutter)
- Android Studio or VS Code with Flutter extension
- An emulator or physical device for testing

### Installation & Setup

1. Clone this repository:
   ```bash
   git clone <repository-url>
   cd ISA-APP-DEV
   ```

2. Install dependencies:
   ```bash
   flutter pub get
   ```

3. Run the app:
   ```bash
   flutter run
   ```

## Features

The ISA Task App includes a range of features designed to enhance productivity:

- Create, read, update, and delete tasks
- Categorize and organize tasks
- Mark tasks as complete
- Responsive and intuitive user interface
- Cross-platform compatibility (iOS and Android)
